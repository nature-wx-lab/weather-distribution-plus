# 天気分布予報プラス

Nature Wx Lab の公開用静的プロトタイプです。気象庁データをもとに、予測・実況・平均との差・前日差を地図で比較できます。

このリポジトリには、静的サイト本体、公開表示に必要な加工済みデータ、GitHub ActionsでJMA公開データを更新するスクリプトを置きます。ローカル専用のSQLite、HTMLキャッシュ、個人メモ、認証情報は含めません。

10分更新では新しい候補を完全データ契約で検査し、不整合な候補を公開しません。予報だけがJMAの配信切替中で不整合な場合は、最新実況と直前の正常予報を再検査して公開します。それも成立しない場合は直前の完全正常版を保持し、実況35分または保持予報13時間の回復上限を超えた時だけworkflowを失敗させます。単発の取得404や更新時差はActions上のwarningとして残し、長時間の更新停止は従来どおりfailureで通知します。

実況日別値はJMA全アメダス温度地点の観測値・平年差・前日差を0.1度格子へIDW補間した表示です。観測地点そのものの公式値はJMA「最新の気象データ」を確認してください。
